# Prompt Roulette

恋愛ロール向けのメインお題と補助条件を、ランダムに組み合わせる静的Webアプリです。

## 現在の機能

- メインお題をカテゴリ指定で抽選
- 補助条件を有効な種類から重複なく抽選
- メイン・各補助条件の個別引き直し
- 表示する補助条件の数を変更
- 組み合わせを貼り付け用テキストとしてコピー
- 呼びかけや前置きを含むコピー文テンプレートを自由に編集・保存
- 地雷ワードと個別のお題を抽選対象から除外
- 全メインお題を検索・分類・抽選状態で絞り込み表示
- 直近20件の抽選履歴
- 組み合わせ単位のお気に入り保存
- 設定・コピー文・地雷リスト・履歴・お気に入りをブラウザ内に保存
- スマートフォン対応、ダークモード対応、簡易オフライン対応

外部APIやCDNは使用していません。

## ファイル構成

- `index.html`: 画面構造
- `styles.css`: レイアウトと見た目
- `prompts.js`: メインお題・カテゴリ・補助条件のデータ
- `core.js`: 地雷判定とコピーテンプレート展開の共通処理
- `app.js`: 抽選、コピー、履歴、お気に入りなどの処理
- `manifest.webmanifest` / `sw.js`: ホーム画面追加と簡易オフライン対応

## お題を増やす

`prompts.js` の `prompts` 配列へ、次の形式で追加します。

```js
{
  id: "category-連番",
  category: "カテゴリID",
  text: "AIへ渡すお題本文",
  tags: ["タグ1", "タグ2"]
}
```

補助条件は `modifiers` 内の各 `values` 配列へ追加します。

## 公開

GitHub Pages の公開元を `main` ブランチの `/ (root)` に設定すると、そのまま動作します。
